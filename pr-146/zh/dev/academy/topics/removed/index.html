本页内容

The following addons have been removed from the Index for various reasons.

If you think of creating a new addon, have a look at this list, maybe you can rework, extend or maintain an existing project instead of starting from scratch.

All of the addons listed have the base reason for removal being obsolete, outdated or unmaintained, anything of note is listed in the Details column.

Addon Details
Modern UI Alternative toolbar layouts.
OSE 3D Printer Workbench for designing 3D printers.
Glass Transparent tree viewer overlay.
RemBench Activates workbenches based on document.
GDT Geometric Dimensioning and Tolerancing.
Help Help system showing relevant documentation.
BIM Building Information Modeling workbench.
ExtMan Alternative to the Addon Manager.
Autoload Automatically pre-loads workbenches.
Flamingo Tools to draw frames and pipelines.
Timber Tools for framing houses.
Retr3d Creating 3D printers from e-waste.
Reconstruction Reconstruct models from images.
Persistent Toolbars Restores toolbar positions.
Navigation Indicator Controls for the navigation style.
Cura Engine Integration of the Cura engine.
Assembly 2 Legacy assembly workbench.
BIM Bots Integration with the BIMBots service.
Extreme Pro Light Light theme.
Extreme Pro Dark Dark theme.
Vendor Parts Unknown
Geo Data Geographic data support.
Exploded Assembly Explode assemblies into its parts.
Lattice Tools for working with arrays of parts.
