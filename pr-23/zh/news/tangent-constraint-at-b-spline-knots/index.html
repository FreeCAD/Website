Tangent Constraint at B-Spline Knots

2022年12月28日 Chris Hennes (80)Feature (18)Sketcher (8)131 字1 分钟

This past week marked the merge of a feature that’s been in development since October: the ability to apply a tangency constraint to a line segment at B-spline knot points. In addition, the B-Spline knots themselves can now be constrained as any other point in Sketcher.

Developer Ajinkya Dahale has been working to develop this new feature as part of the B-Spline Constraint Project. Many thanks to Ajinkya, as well as to Sketcher Lead Maintainer Abdullah Tahiri, for their hard work on this project.

The B-Spline Constraint Project is funded in part by the FreeCAD Project Association Development Fund (FPADF). If you have a project you are interested in undertaking and are want to apply for a grant to assist in your efforts, read more about the FPADF here.
