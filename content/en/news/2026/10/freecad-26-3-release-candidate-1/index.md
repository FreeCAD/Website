The FreeCAD team has just announced the first release candidate for FreeCAD 26.3. If you've been waiting to get your hands on [new features](https://wiki.freecad.org/Release_notes_26.3/en) and help by reporting bugs, this is a great time to start.

What we need from you:

- [Download the build](https://github.com/FreeCAD/FreeCAD/releases/tag/26.3rc1) for your operating system from the assets below and run it against your own work. Real models and real workflows find things that test suites do not.
- [Report](https://github.com/FreeCAD/FreeCAD/issues) anything new and not yet reported on GitHub (please use the search).
- Regressions against version 1.1 are the most valuable reports at this stage. If something worked in 1.1 and does not work here, say so explicitly.

The issue tracker on GitHub has a list of [open blockers and known critical issues](https://github.com/FreeCAD/FreeCAD/issues?q=is%3Aissue%20state%3Aopen%20label%3A%22Blocker%22). We expect the number of those to temporarily go up in the coming weeks as people discover issues and report them. There will likely be several release candidates a few weeks apart, each with more fixes.
