### Donations Frequently Asked Questions

{{< details summary="Why donate to FreeCAD?" name="faq" >}}

FreeCAD is run entirely by community members. All donations go to the non-profit [FreeCAD Project Association AISBL](https://fpa.freecad.org/) (FPA), which are then used for its [Initiatives](https://fpa.freecad.org/programs.html), including but not limited to: development grants, travel grants, and bug bounty payouts. Visit the [Accepting donations](https://fpa.freecad.org/handbook/process/accepting-donations.html) page for more details.

{{< /details >}}

{{< details summary="How is the money spent?" name="faq" >}}

Check out the [Bookkeeping](https://fpa.freecad.org/handbook/process/bookkeeping/overview.html) page to see how the resources are allocated.

{{< /details >}}

{{< details summary="How to donate?" name="faq" >}}

It is possible to commit to monthly donations called *sponsorship* or make one-time donations using the payment methods provided by the form on the top of this page. Monthly *sponsorship* grants a sponsor level depending on the amount.

{{< /details >}}

{{< details summary="Sponsorship Tiers" name="faq" id="tiers" >}}

| Tier | Minimum amount per month | Feature |
| --- | --- | --- |
| **Normal** | 5 EUR / 5 USD | No name listed on this page, but helps the project a lot. |
| **Bronze** 🥉 | 25 EUR / 25 USD | Name or company name listed on this page. |
| **Silver** 🥈 | 100 EUR / 100 USD | Name or company name, link to website, and one-line description listed on this page. |
| **Gold** 🥇 | 200 EUR / 200 USD | Name or company name, logo, link to website and custom description listed on this page. |

{{< /details >}}

{{< details summary="Corporate sponsorship" name="faq" id="corporate" >}}

The **Corporate sponsorship** level is accessible from 1000 EUR / 1000 USD per month. Please contact the [FreeCAD Project Association AISBL](https://fpa.freecad.org/programs.html) to learn more about Corporate sponsors.

The *FPA* accepts donations from individuals and corporations alike. Donations solely aimed at placing companies' links on the Donate page are not accepted. Sponsors must have some form of relationship with the FreeCAD project. For more information, visit the [Accepting donations](https://fpa.freecad.org/handbook/process/accepting-donations.html) page.

{{< /details >}}
